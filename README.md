# Vimtoria

**Vimscript のみで動く、Paradox「Victoria 3」風の経済グランドストラテジー。**

舞台は 1836 年の地球(**37カ国・78州**)。あなたは一国を選んで担当し、
建物を建て、税率と法律を操り、技術を研究し、外交と戦争で版図を広げながら
国を近代化させる。すべてが Vim のバッファの中で動く。

- 外部依存なし(Lua・Python・外部バイナリ不使用)。純粋なレガシー Vimscript
- Vim 8.2+ / Neovim 両対応
- **日本語版と英語版** — 起動時に表示言語を選択。UI・州名・イベントまで全対応
- 37 の国民市場で毎週、生産 → 需給価格 → 賃金・雇用 → 財政のサイクルが回る
- AI 国も研究・建設・増税・同盟・宣戦を行う、生きた世界

## 必要環境

| 項目 | 要件 |
|---|---|
| エディタ | Vim 8.2+ または Neovim(`timer_start()`・`getmousepos()`・JSON 関数を使用) |
| ターミナル | **横幅 200 桁以上を推奨**(世界地図が 200×37 文字)。フォントを小さくすると快適 |
| 依存 | なし。プラグインマネージャも不要 |

## インストールと起動

任意のプラグインマネージャで `miraihack/Vimtoria` を追加するか、
クローンして runtimepath に加えるだけ:

```sh
git clone https://github.com/miraihack/Vimtoria.git
nvim --cmd "set rtp^=$PWD/Vimtoria" +Vimtoria
```

vim-plug の例:

```vim
Plug 'miraihack/Vimtoria'
```

`:Vimtoria` で起動すると、まず**言語選択画面**(日本語 / English)、続いて
**国選択画面**が開く。37カ国の州数・人口・労働力・
陸軍・経済体制を見比べ、`j/k` + `Enter` でプレイする国を決める。
大国(英・清・露…)は経済も軍も強いが研究は頭打ちしやすく、
小国は身軽だが油断すると併合される。

ゲームは 1836 年 1 月 1 日・**停止状態**で始まる。`Space` で時間が流れ、
1 ティック = ゲーム内 1 週間。`1`〜`4` で速度を変えられる。
ヘルプは `:help vimtoria`。

## 遊び方ガイド

### 経済 — すべての土台

各国は一つの国民市場を持ち、財 10 種(穀物・綿花・木材・石炭・鉄・鋼鉄・
工具・衣類・家具・サービス)が毎週取引される。価格は Victoria 3 と同型の
需給式で動く:

```
価格 = 基準価格 × (1 + 0.75 × (買い注文 − 売り注文) / max(買い, 売り))
```

不足した財は高騰し(±75% でクランプ)、それを作る建物が儲かる。
この価格シグナルがプレイヤーと AI の両方の行動を駆動する。

- **建物** 1 レベル = 雇用 10 千人。粗利は賃金と配当に分配される(比率は労働法で変わる)
- 黒字の建物は失業者(**自給農**)から雇用を増やし、赤字なら減らす
- 失業者は毎週少しずつ、求人のある州へ**移動**する(`gp` の Pop 画面で観察できる)
- 前週の**生活水準**が高いほど Pop の消費は増える(需要係数 0.5〜1.5 倍)

### 建設(`gc`) — プレイヤーの主動詞

マップで自国の州を選んでから建設画面を開き、建物をキューに積む。
建設力(労働力比例、技術・法律・イベントで増減)が毎週キューの先頭から
消化され、**1 ポイントごとに木材・工具・鋼鉄を市場価格で購入**する。
大量に建てるほど資材が高騰する — 先に伐採所と工具工房を建てるのが定石。

### 予算(`gb`)と国債

収入は所得税(`+`/`-` で税率変更)、支出は政府維持費・軍事費・利払い・建設費。
増税すると生活水準が下がり、急進性が上がりやすくなる。
国庫は**信用限度(週間所得の 50%)まで負にできる**ので、赤字国債で
先行投資が可能。ただし債務には年利 5%(中央銀行の研究で 3%)がかかる。

### 技術(`gt`)

10 技術のツリー。研究力は労働力の**平方根**でスケールする(大国ほど速いが
線形ではない)。研究対象は途中で切り替えても進捗が per-tech に保存される。

| 系統 | 技術 | 効果 |
|---|---|---|
| 農業 | 輪作 → 農業機械化 | 農場の産出 +20% → さらに +30% |
| 工業 | 蒸気機関 → 工作機械 / 力織機 / 転炉製鋼 | 鉱山 +25% / 工具 +30% / 織物 +40% / 製鉄 +50% |
| インフラ | 株式会社 / 鉄道 | 建設力 +25% / +50%(鉄道は石炭を毎週消費 — 炭鉱を先に!) |
| 社会 | 公教育 / 中央銀行 | 研究力 +25% / 国債年利 5%→3% |

### 政治(`gv`)

利益集団(**地主・実業家・労働運動**)の勢力は、支持基盤の職業の所得シェアで
毎週変わる。工業化を進めるほど実業家と労働運動が台頭する。

法律は 3 グループ 6 種(農本主義/産業奨励、自由放任/労働保護、地租/所得税)。
制定には約 26 週かかり、勢力加重の支持が高いほど速い。**支持が負のまま
強行すると急進性が上がり**、急進性 60 超で反乱(全産出 -20%)の危険がある。
税率の上限は税制の法律で決まる(地租 15% / 所得税 30%)ので、
重税国家への道はまず地主を説得するところから。

### 外交(`gd`)と軍事(`ga`)

- **関係値**(-100〜+100)。露土 -40、墨テキサス -60 など 1836 年の確執が
  プリセットされている。関係改善は £10,000 で +15(26 週に 1 回)
- 関係 60 以上で**同盟**。同盟国は防衛戦争に参戦する
- **連隊**の徴募は資金と労働力を消費し、軍は毎週、金と物資(穀物・衣類・工具)
  を消費する — 軍拡も市場を動かす
- **宣戦布告**の奪取目標は、マップで選択中の相手領の州。戦争は毎週戦況が動き
  (戦力比+乱数、±100 で決着)、攻撃側が勝てば**目標州を併合**する。
  併合した州は建物・Pop ごと手に入り、マップの国色も塗り替わる
- AI 国も同盟を組み、弱った仇敵に宣戦する。孤立した弱国は危ない

### イベントと世界ニュース

毎週低確率で豊作・凶作・鉱山事故・労働争議・建設ブーム・疫病・移民などが
発生する。自国のイベントと世界の戦争ニュースはマップ下部の
「最近の出来事」に流れる。

### スコアとセーブ

勝利条件のないサンドボックス。`gr` の**列強ランキング**(週間GDP・生活水準・
技術数・陸軍・国庫)が順位の目安になる。`S` でセーブ、`L` でロード
(JSON 1 ファイル、既定 `~/.vimtoria_save.json`)。

## キー操作一覧

| キー | 動作 |
|---|---|
| `Space` | 停止 / 再開(起動時は停止中) |
| `1`〜`4` | ゲーム速度(1 ティック = ゲーム内 1 週間) |
| `h j k l` | マップ: 州を選択 / メニュー画面: 項目選択 |
| マウスクリック | マップ: 州名をクリックで選択(選択中の州を再クリックで詳細) |
| `Enter` | マップ: **カーソルが州名の上ならその州**、それ以外は選択中の州の詳細 / 建設: キュー追加 / 技術: 研究開始 / 政治: 制定開始 / 言語・国選択: 決定 |
| `gm` `gb` `gc` `gt` `gp` `gr` | 市場 / 予算 / 建設 / 技術 / Pop / 列強 画面 |
| `gv` `gd` `ga` | 政治 / 外交 / 軍事 画面 |
| `x` | 建設画面: キュー末尾を取消 |
| `+` `-` | 予算画面: 税率を変更(上限は税制の法律で決まる) |
| `i` `a` `w` `p` | 外交画面: 関係改善 / 同盟・破棄 / 宣戦布告 / 白紙和平 |
| `r` `d` | 軍事画面: 徴募 / 解散(5 個連隊ずつ) |
| `S` `L` | セーブ / ロード |
| `Esc` | どのサブ画面からでも世界地図へ戻る |
| `q` | サブ画面からマップへ戻る。マップ上では終了(確認あり) |

ゲーム中は `mouse=a` が自動設定され、終了時に元の値へ復元される。

## 設定

| 変数 | 既定 | 説明 |
|---|---|---|
| `g:vimtoria_lang` | (なし) | `'ja'` / `'en'`。設定すると言語選択画面を飛ばしてこの言語で表示 |
| `g:vimtoria_player_country` | (なし) | 設定すると国選択画面を飛ばしてこの国で開始(例 `'GBR'`) |
| `g:vimtoria_save_file` | `~/.vimtoria_save.json` | セーブファイルのパス |
| `g:vimtoria_disable_events` | `0` | `1` でランダムイベントの自動発生を停止 |

## 1836年の世界

37カ国・78州。テキサス共和国(独立直後)、ペルー=ボリビア国家連合(成立直後)、
ムハンマド・アリー朝エジプト、ズールー王国、ソコト帝国、マダガスカル王国、
ハワイ王国など、1836 年に実在した国家を収録。列強は複数州を持つ:

| 国 | 州 |
|---|---|
| 日本(江戸幕府) | 蝦夷地・奥羽・江戸・上方・西国・九州 |
| イギリス | 本国・英領カナダ・北インド・ベンガル・ボンベイ・マドラス・豪州・NZ |
| 清 | 満洲・直隷・江南・広東・四川・新疆・チベット・雲南 |
| ロシア帝国 | 中央ロシア・ウクライナ・カフカス・ウラル・シベリア・露領アメリカ |
| アメリカ合衆国 | ニューイングランド・東部・南部諸州・西部領 |
| オスマン帝国 | アナトリア・ルメリア・メソポタミア・チュニス |

世界地図は `tools/gen_map.py` が**緯度経度の海岸線ポリゴン**(27 陸塊+
黒海・カスピ海)をラスタライズして生成する。州アンカーは実座標で配置され、
衝突はビルド時に検査される。描画時にアンカー位置へ州名ラベル(表示言語に
応じて日本語名 / 英語正式名称)が重ねられる。地図を改良したいときはポリゴンを編集して
再生成するだけ:

```sh
python3 tools/gen_map.py            # data/map_ascii.vim を再生成
python3 tools/gen_map.py --preview  # 端末でプレビュー
```

## アーキテクチャ

```
plugin/vimtoria.vim          :Vimtoria コマンド定義のみ(遅延ロード)
autoload/vimtoria/
├── core.vim                 ゲームループ・時間・状態ストア・入力ディスパッチ
├── econ.vim                 市場・生産・雇用・賃金・財政(週次ティックの心臓部)
├── build.vim                建設キュー・建設力・信用限度
├── tech.vim                 技術ツリーとモディファイア
├── politics.vim             利益集団・法律制定・急進性
├── diplo.vim                関係値・同盟・宣戦・和平
├── war.vim                  連隊・戦闘解決・州の併合
├── ai.vim                   AI 国の研究/財政/建設/外交
├── events.vim               ランダムイベント(時限モディファイア)
├── map.vim                  州選択ナビゲーション
├── i18n.vim                 表示言語(日本語/英語)と UI 文字列辞書
├── ui.vim                   バッファ管理・描画・キーマップ・マウス
├── data.vim                 data/ のローダ(前計算キャッシュ付き)
└── screens/                 各画面 = 「状態 → 行リスト」の純関数
data/
├── map.vim                  国・州の定義(名前・人口・首都・色)
├── map_ascii.vim            世界地図テンプレート(自動生成)
├── economy.vim              財・建物・職業・需要・各種定数
├── tech.vim                 技術ツリー定義
├── politics.vim             利益集団・法律定義
├── diplomacy.vim            外交定数・1836年の関係プリセット
└── events.vim               イベント定義
syntax/vimtoria.vim          画面ハイライト(国色は matchadd で動的に)
doc/vimtoria.txt             :help vimtoria
tools/gen_map.py             世界地図ジェネレータ
test/                        ヘッドレステスト 7 スイート
```

設計原則:

- **状態は一箇所** — ゲーム状態全体が単一の辞書。セーブは `json_encode` 一発
- **描画は純関数** — 各画面は「状態 → 行リスト」を返すだけ。tick と描画は分離
- **データ駆動** — 財・建物・技術・法律・イベント・地図はすべて `data/` の
  辞書定義。バランス調整と Mod が容易
- **互換レイヤなし** — Vim/Neovim 共通の API(`timer_start`・`setbufline`・
  `matchadd`・`getmousepos`)だけを使う
- **性能** — 37 市場 × 78 州の週次ティックが Neovim で約 38ms、Vim 9 で約
  53ms(予算 58ms)。静的 `items()` の事前展開や価格式のインライン化など、
  VimL の特性に合わせて最適化してある

## テスト

```sh
test/run.sh
```

Neovim と(本物の)Vim の両方が見つかれば、7 スイートをそれぞれで
ヘッドレス実行する。価格式の境界値、10 年(520 週)回しても価格・雇用・
国庫が発散しない長期安定性、戦争による併合の整合性、セーブ/ロードの
復元、性能予算などを検証している。
